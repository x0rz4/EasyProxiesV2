# 解锁检测页布局与计数修复

日期：2026-10-26。目标版本：2.2.13。

## 设计与范围

参考 manage 页恢复整页滚动，同时保留节点表格内部的纵横滚动和固定表头。移除五张统计卡片、标签归属提示和重复计数行，保留诊断筛选按钮。

仅展示运行态节点，包括待检查、不可用、黑名单节点。筛选分页栏统一显示本页、匹配和运行节点总数，分别使用查询 items、查询 total 和运行态 facets total；不使用健康数量。共享筛选栏的默认显示保持兼容，仅解锁页启用新计数模式。

查询页是展示和选择的依据；详情暂缺时显示“运行态更新中”并禁止单节点操作，不丢弃行。越界页自动收敛到最后有效页，加载和失败不伪装成零计数。不修改后端接口或数据库结构。
