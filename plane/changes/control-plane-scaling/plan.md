## 提交顺序

- [x] Q1 节点查询读事务：使用 SQLite 读连接池的一致性事务，避免全量视图与诊断事实加载占用唯一写连接。验证 WAL 快照、并发写入、只读约束和嵌套事务。
- [ ] Q2 SSE 终态与生命周期：原子订阅初始状态，终态不能被缓冲区溢出丢弃；写入失败、慢客户端与服务关闭均能退出。验证完成竞态、满队列和断开。
- [ ] Q3 有界退出：取消生产者、停止消费者、最后刷新与关闭资源共用退出预算；标签重算和统计写入必须接收取消。验证阻塞工作取消、幂等关闭及正常刷新。
- [ ] Q4 订阅刷新流水线：下载并发与待提交结果同时有界，按订阅顺序提交；保留版本门禁、窄写、失败保留和最终一次运行时对账。验证慢首项、取消与并发编辑。
- [ ] Q5 自愈定向重查：规划后每个阶段及动作只重读目标分组，保留最新策略和成员资格校验，避免反复重建所有分组输入。验证策略变更、预算与调用范围。
- [ ] Q6 前端分页详情：管理页与检测页按当前页 ID 加载详情与结果，批量选择使用服务端 query-ids；保持跨页操作和编辑凭据访问权限。验证 API ID 过滤、前端 lint/build。
- [ ] Q7 API Key 使用记录：固定消费者按 key ID 合并、节流、重试并有界关闭，避免每请求启动 goroutine 和写事务。验证最新时间、失败保留及退出。
