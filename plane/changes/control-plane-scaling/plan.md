承接资源稳定性修复后的七项审查发现。每项独立修改、验证并提交；最后统一递增 patch 版本。当前形态随实现更新到 `docs/`，此处保留问题、设计取舍与验收证据。

## 提交顺序

- [x] Q1 节点查询读事务：使用 SQLite 读连接池的一致性事务，避免全量视图与诊断事实加载占用唯一写连接。验证 WAL 快照、并发写入、只读约束和嵌套事务。
- [x] Q2 SSE 终态与生命周期：原子订阅初始状态，终态不能被缓冲区溢出丢弃；写入失败、慢客户端与服务关闭均能退出。验证完成竞态、满队列和断开。
- [x] Q3 有界退出：取消生产者、停止消费者、最后刷新与关闭资源共用退出预算；标签重算和统计写入必须接收取消。验证阻塞工作取消、幂等关闭及正常刷新。
- [x] Q4 订阅刷新流水线：下载并发与待提交结果同时有界，按订阅顺序提交；保留版本门禁、窄写、失败保留和最终一次运行时对账。验证慢首项、取消与并发编辑。
- [x] Q5 自愈定向重查：规划后每个阶段及动作只重读目标分组，保留最新策略和成员资格校验，避免反复重建所有分组输入。验证策略变更、预算与调用范围。
- [x] Q6 前端分页详情：管理页与检测页按当前页 ID 加载详情与结果，批量选择使用服务端 query-ids；保持跨页操作和编辑凭据访问权限。验证 API ID 过滤、前端 lint/build。
- [x] Q7 API Key 使用记录：固定消费者按 key ID 合并、节流、重试并有界关闭，避免每请求启动 goroutine 和写事务。验证最新时间、失败保留及退出。

## 验证记录

Q1：新增 WithReadTx 并迁移节点视图；读快照内并发写入、快照稳定性、嵌套只读约束回归通过。go test ./internal/store ./internal/httpapi 全部通过。

Q2：原子订阅与初始快照、满队列保留终态、十秒写期限和心跳/关闭退出已实现。完成发生于首次 Flush、已完成、满队列、写失败和服务退出回归连续三轮通过。

Q3：装配根统一三十秒退出预算与逆序清理，生产者先取消，统计/状态最终落库共享预算；标签重算可取消，订阅和综合检测 worker 收拢后才关闭 store。不可取消第三方 Close 由单一清理协程隔离，超时返回错误且不打乱资源顺序。新增预算/资源顺序、幂等关闭、活动重算取消回归；app/nodetag/subscription/boxmgr/httpapi 包测试通过。

Q4：三槽位抓取/有序提交流水线，最多三份未提交结果，释放 payload 后开放下一次抓取；保留窄写、版本门禁与一次运行时对账。新增慢首项背压、后续慢项不阻塞早期提交、取消退出回归；完整 subscription 包通过。

Q5：新增目标分组输入与只读运行快照，阶段、晋升、探测、刷新动作全部迁移；全轮仅一次全组读取。新增读取次数、最新禁用策略和无关组持锁隔离回归；group/boxmgr/app 全包通过，既有预算、恢复与审计失败测试保持通过。

Q6：管理/检测页详情、运行态与检测结果改为按当前页 ID 读取，跨页动作保存 ID；全局计数来自 facets，批量探测按需分批读详情。新增可见性与空 ID 不放宽、非法/重复/超量 ID、只调用 ByIDs、禁用节点详情回归。store/httpapi/boxmgr 全包及前端 lint/build 通过，构建仍有既有 chunk 大小提示。

Q7：Auth 惰性单消费者、按 Key 合并最新时间、每分钟节流、五秒失败重试和退出最终落库；1024 项硬上限与显式溢出日志，换库代际隔离，SQL 时间单调更新。虚拟时间回归覆盖千次突发、最新观测、重试、同库重绑、换库隔离、关闭超时和容量边界；controlplane/httpapi/store 全包通过，定向用例连续三轮通过。
