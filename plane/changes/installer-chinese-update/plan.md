# 安装器中文提示与显式更新

日期：2026-10-26。目标版本：2.2.14。

## 实施约定

- 默认安装目录为 `/opt/easy-proxies`，无需参数即可安装；保留 `--dir` 自定义目录，不把应用文件散放在 `/opt` 根目录。
- 帮助、安装/更新进度、成功与错误提示使用中文；参数、服务标识及系统命令输出保持兼容，不引入必须回答的交互。
- 新增 `--action update` 与 `--update`，支持最新稳定 Release 或指定版本；更新要求已有对应安装，避免把路径输错当成新安装。
- 下载和 SHA256 校验完成后替换二进制；保留配置、节点文件和数据库。默认更新保留服务运行状态及自启状态，仅重启原本运行的服务；`--no-start` 仅更新文件。Docker 更新保留托管容器的挂载目录、运行状态与 restart policy，镜像拉取失败不移除旧容器。
- 更新失败不记录成功版本，不承诺应用启动或数据库迁移失败后的自动回滚。服务、容器归属冲突在下载及替换前拒绝。
